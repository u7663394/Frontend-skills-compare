# Product

## Register

brand

## Users

Visitors are recruiters, collaborators, classmates, and open-source peers evaluating Guochen Wang's technical direction from a public portfolio surface. They are scanning quickly for identity, current focus, credible projects, and contact paths.

## Product Purpose

This project compares how different frontend skills produce the same personal introduction homepage brief. The Impeccable implementation should present Guochen Wang as an ANU Advanced Computing Honours student working across machine learning, computer vision, and frontend development, with clear project evidence and a polished personal voice.

## Brand Personality

Precise, curious, maker-minded. The page should feel like a computational notebook turned into a personal site: technical, composed, and visibly hands-on.

## Anti-references

Do not borrow implementation or design patterns from `Design-Taste-Frontend/`, `Frontend-Skill/`, or `Web-Design-Engineer/`. Avoid generic GitHub badge walls, repeated icon-card grids, gradient text, side-stripe accents, glassmorphism, and template SaaS portfolio sections.

## Design Principles

- Lead with the person, then the work evidence.
- Make technical breadth legible without turning the page into a resume dump.
- Use project details from the GitHub profile, but rewrite them into concise public-site copy.
- Let motion and visual systems suggest machine vision and frontend craft without hiding content.
- Prefer clear links and readable contrast over decorative status badges.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-accessible links, semantic sections, descriptive link text, and reduced-motion alternatives for all animation.
