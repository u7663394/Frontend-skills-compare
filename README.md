This repository compares the output of several frontend-oriented skills under the same product brief. Each implementation is a Vue 3 + TypeScript personal introduction homepage inspired by the content of [u7663394's GitHub profile](https://github.com/u7663394).

## Unified Prompt

> Create a Vue 3 + TypeScript personal introduction homepage. Use the content inspiration from this GitHub profile: https://github.com/u7663394.

## How to Run

Each demo is an independent Vite project. Open the directory you want to inspect, install dependencies if needed, and start the development server:

```bash
cd Design-Taste-Frontend
npm install
npm run dev
```

Use the same workflow for the other output directories.

## Evaluation Notes

Frontend design quality is highly subjective, and agent-generated results can vary significantly between runs even with the same prompt. The notes below only reflect my own impression from this comparison. They are not intended as an objective ranking of the skills themselves.

- Test agent: Codex, GPT 5.5 High
- Personal impression: Web Design Engineer ≈ Design Taste Frontend > Impeccable > Frontend Skill
